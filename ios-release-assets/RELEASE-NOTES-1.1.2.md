# 1.1.2 업데이트 내역 (App Store "이번 버전의 새로운 기능")

## 한국어

```
• 캐릭터 진화시키기 — 함께 지낸 캐릭터를 원하는 모습으로 진화시켜요
• 캐릭터 이름 — 만들 때 붙인 이름이 홈 문구·알림·갤러리에 함께 나와요
• 캐릭터 갤러리 — 캐릭터별로 모아 보고, 길게 눌러 이름 변경·삭제할 수 있어요
• 연속 이미지의 1번째/2번째 순서를 바로 바꿀 수 있어요
• 새 픽셀 글꼴과 아이콘으로 화면을 전체적으로 다듬었어요
• 만들기 화면을 정리했어요 — 만드는 중 표시, 실패했을 때 이유 안내
• 수면은 설정한 시간을 기준으로 인식해요
• 첫 만들기는 무료, 시작할 때 캔디도 넣어 뒀어요
그 밖에 화면 전환·뒤로가기·갤러리 표시 오류를 고쳤어요.
```

## English

```
• Evolve Character — grow the character you've spent your days with into the form you want
• Character names — the name you give appears in Home captions, notifications, and the gallery
• Character Gallery — browse by character, and long-press to rename or delete
• Swap the 1st/2nd frame of an animated character right from the detail view
• A new pixel typeface and icons throughout the app
• A cleaner creation flow — clear progress while it's drawing, and a reason when it fails
• Sleep is now recognized from the hours you set
• Your first creation is free, with candy waiting when you start
We also fixed navigation, swipe-back, and gallery status issues.
```
